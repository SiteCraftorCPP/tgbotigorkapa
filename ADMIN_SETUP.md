# 👥 Настройка администраторов

## Важно!

Все настройки бота управляются через Telegram **ТОЛЬКО администраторами**, которые прописаны в БД.

## Шаг 1: Узнать свой Telegram ID

### Способ 1: Через @userinfobot

1. Найдите бота @userinfobot в Telegram
2. Отправьте ему `/start`
3. Он пришлёт ваш ID (например: `123456789`)

### Способ 2: Через @getmyid_bot

1. Найдите бота @getmyid_bot в Telegram
2. Отправьте ему любое сообщение
3. Получите ваш ID

## Шаг 2: Добавить админов в БД

### После создания БД выполните:

```sql
-- Первый админ
INSERT INTO admins (telegram_id, username, first_name) 
VALUES ('ВАШ_TELEGRAM_ID', 'ваш_username', 'Ваше Имя');

-- Второй админ
INSERT INTO admins (telegram_id, username, first_name) 
VALUES ('ID_ВТОРОГО_АДМИНА', 'username_админа', 'Имя Админа');
```

### Пример:

```sql
INSERT INTO admins (telegram_id, username, first_name) 
VALUES ('123456789', 'crypto_trader', 'Ivan');

INSERT INTO admins (telegram_id, username, first_name) 
VALUES ('987654321', 'second_admin', 'Petr');
```

### Через psql:

```bash
psql -U postgres -d crypto_signals

-- Затем выполните INSERT запросы выше
```

### Через pgAdmin:

1. Откройте pgAdmin
2. Подключитесь к БД `crypto_signals`
3. Tools → Query Tool
4. Вставьте SQL запросы
5. Execute (F5)

## Шаг 3: Проверка

SELECT * FROM admins;

## Управление админами через Telegram

### После добавления первых админов в БД:

Админы могут добавлять других админов прямо из Telegram:

```
/add_admin 111222333
```

Удалить админа:

```
/remove_admin 111222333
```

Список админов:

```
/list_admins
```

## Проверка прав

Отправьте боту:

```
/start
```

Если вы админ, вы увидите расширенное меню с админ-командами.

Если нет - только публичные команды.

## Админ-команды

### Управление ботом:
- `/enable` - Включить бота
- `/disable` - Выключить бота
- `/config` - Текущие настройки

### Настройка параметров:
- `/set_pairs BTC/USDT ETH/USDT` - Изменить торгуемые пары
- `/set_timeframes 5m 15m 1h` - Изменить таймфреймы
- `/set_ai_score 75` - Минимальный AI Score (0-100)
- `/set_risk 1.5` - Процент риска на сделку
- `/set_leverage 20` - Плечо по умолчанию

### Управление админами:
- `/add_admin USER_ID` - Добавить админа
- `/remove_admin USER_ID` - Удалить админа
- `/list_admins` - Список всех админов

## Примеры использования

### Включить бота и настроить параметры:

```
/enable
/set_pairs BTC/USDT ETH/USDT SOL/USDT
/set_timeframes 15m 1h 4h
/set_ai_score 75
/set_risk 2.0
/set_leverage 15
/config
```

### Добавить третьего админа:

```
/add_admin 555666777
```

### Посмотреть текущие настройки:

```
/config
```

Ответ:
```
⚙️ Текущие настройки бота

🤖 Статус: ✅ Включен

📊 Торговля:
• Пары: BTC/USDT, ETH/USDT, SOL/USDT
• Таймфреймы: 15m, 1h, 4h

🎯 Параметры:
• Мин. AI Score: 75/100
• Риск: 2.0%
• Плечо: x15
```

## Безопасность

1. ✅ **Только админы** могут управлять настройками
2. ✅ **Нельзя удалить последнего админа**
3. ✅ Все изменения логируются в админ-канал
4. ✅ Telegram ID проверяется для каждой команды

## Важные заметки

- Храните Telegram ID в секрете
- Не давайте права админа неизвестным людям
- Регулярно проверяйте список админов (`/list_admins`)
- Все настройки хранятся в БД, а не в `.env`

## Если забыли пароль БД или потеряли доступ

1. Подключитесь к серверу с PostgreSQL
2. Сбросьте пароль или добавьте себя как админа через SQL
3. Или пересоздайте БД и добавьте админов заново

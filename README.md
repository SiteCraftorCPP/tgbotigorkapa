# 🛡️ Ультраконсервативный Крипто-Сигнальный Бот

**Telegram-бот для максимально безопасной торговли криптовалютными фьючерсами на XT.com**

## 🎯 Философия

Бот работает как идеальный консервативный трейдер:
- ✅ Множество подтверждений перед входом
- ✅ Минимальный риск (**≤1% на сделку**)
- ✅ Абсолютная дисциплина
- ✅ Полная автоматизация 24/7
- ✅ Прозрачные результаты

## 🔐 Управление Рисками

| Параметр | Значение |
|----------|----------|
| Риск на сделку | **≤ 1%** |
| Суммарный риск | **≤ 5%** |
| Макс. сигналов/сутки | **20** |
| Макс. сигналов на монету | **1** |
| Cooldown после закрытия | **4 часа** |

## 🎯 Торговая Логика

### 4 Уровня Take Profit

После достижения **TP1** - стоп переносится в **безубыток**!

- **TP1** (25%) - RR 1.5:1 → Безубыток
- **TP2** (25%) - RR 2.5:1
- **TP3** (25%) - RR 3.5:1  
- **TP4** (25%) - RR 5:1

### Мультитаймфреймный Анализ

- **Старший ТФ** - определение тренда
- **Младший ТФ** - точка входа (pullback)
- Вход только при совпадении направления

## 🔍 Ультраконсервативные Фильтры

### До генерации сигнала:

1. ✅ **Монеты только из ТОП-100**
2. ✅ **Объём ≥ $5M / 24ч**
3. ✅ **Спред ≤ 0.3%**
4. ✅ **Стоп ≤ 2-2.5 ATR**
5. ✅ **Проверка качества уровня** (мин. 2 касания)
6. ✅ **Дистанция до противоположного уровня** (мин. 1.5 ATR)
7. ✅ **Тренд на 2 таймфреймах**
8. ✅ **Наличие pullback**

## 📊 Технический Анализ

- **Тренд**: EMA 50/100/200, VWAP
- **Моментум**: RSI, Stochastic (+ дивергенции)
- **Объёмы**: Volume MA, сравнение с историей
- **Волатильность**: ATR
- **Свечные паттерны**: разворотные формации

## ⚡ Автоматический Мониторинг

Бот отслеживает **каждые 5 секунд**:

- ✅ Активация входа
- ✅ Достижение TP1/TP2/TP3/TP4
- ✅ Срабатывание SL
- ✅ Перенос в безубыток
- ✅ Условия отмены

## 🚫 Отмена Сигнала (до входа)

Бот отменяет сигнал если:
- ⏱ Истекло 24ч ожидания
- 📉 Цена ушла от зоны входа (>1.5%)
- 🔄 Изменилась структура рынка
- 💥 Сильный импульс против идеи
- 🛑 Цена пробила стоп до входа

## 🛠 Установка

### 1. Клонирование

```bash
git clone <your-repo>
cd tgbotigorkapa
```

### 2. Зависимости

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

### 3. PostgreSQL

```sql
CREATE DATABASE crypto_signals;
```

### 4. .env файл

Создайте `.env`:

```env
XT_API_KEY=4e74f8bf-7424-4521-ba71-ded15621319a
XT_API_SECRET=a0d77d78d99e2b7cec4a941277fccef00877660c

TELEGRAM_BOT_TOKEN=your_bot_token
TELEGRAM_CHANNEL_ID=@your_channel
TELEGRAM_ADMIN_CHANNEL_ID=@admin_channel

DB_HOST=localhost
DB_PORT=5432
DB_NAME=crypto_signals
DB_USER=postgres
DB_PASSWORD=your_password
```

### 5. Добавить админов

```sql
INSERT INTO admins (telegram_id, username, first_name) 
VALUES ('your_telegram_id', 'username', 'Name');
```

См. `ADMIN_SETUP.md` для подробностей.

### 6. Запуск

```bash
python main.py
```
